Abstract

We present an AI engineer specialising in Generative AI, Machine Learning and NLP, with experience designing solutions based on LLMs, retrieval-augmented generation, AI agents and classical ML models. Across four industry roles in banking and manufacturing 124, the subject has covered the full development lifecycle, from data preparation to evaluation, production and API integration. Our main result is a hybrid retrieval pipeline that raises Hit@5 from 0.88 to 1.00 on scientific question answering 5. We conclude that business problems can be turned into robust, operational AI systems that don't invent facts.

1Introduction

Thesis. If a claim can't be traced back to a source, it shouldn't be generated. Language models are good at sounding right. The problem the subject works on is making them be right, and proving it. Every system described below has a measurable success criterion: a retrieval metric, a validator, or a gate that a model must pass before it reaches production.

The contributions of this portfolio are threefold: (i) a citation-grounded RAG system for scientific papers 5; (ii) an incident-triage platform with automated retraining for a banking group 26; and (iii) evaluation tooling that tells you whether a RAG configuration is actually better or just lucky 89.

3Main result: SciRAG 5

SciRAG answers questions over uploaded PDFs, in French or English, and every claim in the answer cites the exact paper, section and page. Scanned pages are OCR'd automatically, and follow-up questions are rewritten into standalone queries before retrieval. It runs fully locally. Source code ↗
Python, FastAPI, ChromaDB, BM25, Sentence-Transformers, Ollama · Llama 3.1, Streamlit, Docker Compose, GitHub Actions

Hybrid retrieval with reranking improves Hit@5 by +12 points over BM25 alone and MRR@5 from 0.78 to 0.94, meaning the right passage is almost always ranked first.

4Further experiments

4.1JobFit AI 7

Tailors a LaTeX CV and cover letter to a job offer without inventing anything. A separate validator checks every generated sentence against evidence in the master CV; requirements you don't meet are reported as missing. The LaTeX layout is kept byte-for-byte. FastAPI, OpenAI API, PostgreSQL, SQLAlchemy, MLflow, Streamlit

4.2Incident AI 6

Triage assistant for banking IT incidents: retrieves similar past incidents, suggests the fix that worked, and predicts priority and team. Airflow ingests tickets hourly with data-quality checks and retrains weekly behind a champion/challenger gate in the MLflow registry. Airflow 3, MLflow, pgvector, multilingual-e5, scikit-learn, Docker

4.3RAG Evaluation Framework 9

A RAG agent plus an evaluation harness measuring answer quality, retrieval accuracy (Hit Rate, MRR) and hallucination rate, used to compare LLM providers (OpenAI, Gemini, Groq) and embedding models. Python, LangChain, Pydantic, DeepEval

4.4RAG Benchmarking Platform 8 in progress

Compares RAG pipelines reproducibly: retrieval, answer and faithfulness metrics per question, with bootstrap confidence intervals and significance tests, so a config is only called better when it is. uv, FAISS, Ollama, SQLite, pytest, mypy
